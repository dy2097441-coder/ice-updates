How it works

  • Iceberg reads updates.txt and compares it with the updates it already has.
  • An update is a .upt file: a checked copy of the system. Iceberg verifies it, writes it to the disk and asks you to restart.
  • Updates are installed on the hard disk, so Iceberg must be set up on a disk first (a Try It session cannot be updated).
  • If your PC is already up to date, the Updates app says so.
